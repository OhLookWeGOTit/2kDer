# 2kDer

**Early Proof-Of-Concept** – A dynamic, real‑time file‑swapping tool for NBA 2K14, inspired by the legendary [Sider](https://github.com/pes-modding/sider7) from the **PES-Modding community**.   
*This project  has a long way to go before a usable release.*
We’re just building on the shoulders of the PES‑Modding community, who created something genuinely groundbreaking with **[Sider7](https://github.com/pes-modding/sider7)**.  


## 🛠 How to Help

We need C/C++ developers with experience in:

- DLL injection (dinput8 proxy)
- Windows API hooking (Microsoft Detours or similar)
- File‑system redirection
- Memory pattern scanning (for future phases)

If you're interested, please open an issue or submit a pull request!
